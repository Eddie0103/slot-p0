## P0 原型怎麼跑

雙擊 `index.html` 即可。實機測試請用手機 Safari 開啟後**加到主畫面**，
從主畫面啟動才是真正的全螢幕直屏（沒有瀏覽器工具列，SPIN 的位置才準）。

進入畫面先點一下「點擊開始」啟動音效——iOS 需要使用者手勢才能啟動 Web Audio，
且機身側邊的靜音開關若在靜音位置，Web Audio 完全不會出聲。
